## Factory Method (Factory Method)- Emissão de Documentos
ATIVIDADE PRÁTICA (IMPRESSA)

Projeto em Java desenvolvido para aplicar o padrão de projeto **Factory Method**.  
O sistema permite gerar diferentes tipos de documentos (**PDF, Word e Planilha**) utilizando fábricas específicas, mantendo o código organizado e desacoplado.

O objetivo é facilitar a criação de novos tipos de documentos sem modificar a lógica principal do sistema.
